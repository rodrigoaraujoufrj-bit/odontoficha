# OdontoFlow - UI E Design

Use este arquivo como primeira mensagem/contexto do chat `OdontoFlow - UI e Design`.

## Objetivo Deste Chat

Cuidar da experiencia visual e usabilidade do OdontoFlow.

## Direcao Visual Atual

O app esta caminhando para:

- sidebar escura azul/teal;
- area principal clara;
- cards discretos;
- botoes arredondados;
- foco clinico;
- odontograma visual;
- tipografia mais leve que a primeira versao.

Referencia aprovada pelo usuario:

- layout com sidebar escura;
- odontograma central;
- ficha resumida do paciente;
- dente selecionado na lateral;
- plano de tratamento abaixo do odontograma;
- resumo de orcamento lateral.

## O Que Evitar

- Cara de landing page dentro do app.
- Cards demais dentro de cards.
- Textos gigantes.
- Interface travada em mobile.
- Botoes administrativos dentro da tela de atendimento.
- Visual muito bruto/pesado.

## O Que Priorizar

- Dentista bate o olho e entende.
- Atendimento fica no centro.
- Odontograma tem destaque.
- Paciente e plano aparecem com clareza.
- Acoes principais ficam obvias:
  - buscar paciente;
  - abrir ficha;
  - iniciar consulta;
  - adicionar procedimento;
  - gerar orcamento.

## Arquivo Principal

- `app.html`

## Pontos A Melhorar

- Ajustar mobile depois das mudancas no odontograma.
- Refinar estados visuais do odontograma.
- Criar header superior mais util.
- Melhorar tela inicial/dashboard.
- Criar estado vazio profissional.
- Criar feedback visual para item editado/excluido.

## Regra Pratica

Antes de mudar componente visual importante, perguntar:

Esta tela e para administrar dados ou para atender paciente?

Se for atendimento, a UI deve ser mais rapida, visual e menos burocratica.
